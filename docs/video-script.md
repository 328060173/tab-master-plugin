### 模块一：标签备份

> 备份是基础。这里分三种：自动监听（重点，最省心）、自动定时、手动。建议三种一起开，互相兜底。

#### 1. 自动监听备份【重点】

**【口播】**
> "先说重点——自动监听备份。这个是我最推荐的一个功能。！！！！！！！！！！！！！！！！！！！！！！！
>
> 开了它之后，插件在后台监听新建标签、关闭标签、做实时同步，自动存一份最新的。不用你记，关掉浏览器那一刻，标价签已经备份好了。
>
>操作步骤：打开浏览器标签大师，顶部的『标签导入导出』按钮，开关在备份页概览最上面这一行，点击「自动监听备份」。第一次打开会弹个告知框，告诉你开启后会发生什么，点「确认开启」就行。
>
> 这时候后标签自动备份就已经开启了，同时在标签列表有一条记录，记录当前标签的个数。我们我们现在打开几个标签、关闭几个标签之后，标签数量会实时变动。"

**【镜头】**
- 进备份管理页 → 概览 Tab。
- 特写顶部「自动监听备份」开关行。
- OFF → ON：弹出首次告知框 → 特写关键两条（后台持续监听 / 启动时自动封存上次会话）→ 点「确认开启」→ 开关变 ON。
- 字幕（停留）：「关掉浏览器那一刻，最新状态已经存好了」

**【操作】**
1. 进备份页概览。
2. 打开「自动监听备份」→ 确认告知框。

#### 2. 自动定时备份

**【口播】**
> "监听是跟着你的操作走，定时是按固定节奏走，双保险。
>
> 概览页点「自动备份」进去设置。频率有四档：10 分钟、15 分钟、30 分钟、60 分钟，默认 10 分钟。它由插件后台定时器跑，侧边栏关着也照样存。
>
> 我建议默认 10 分钟就行，怕丢就调密一点。"

**【镜头】**
- 点「自动备份」进设置弹窗。
- 特写频率下拉：10 / 15 / 30 / 60 分钟。
- 切到 10 分钟演示。
- 字幕：「侧边栏关着也照样存」

**【操作】**
1. 进自动备份设置。
2. 展示四档频率，停在 10 分钟。

#### 3. 手动备份

**【口播】**
> "最后是手动备份。就是你当下想存一份，点一下立刻存。
>
> 概览页第一个按钮「手动备份」，点一下弹个确认框，点「确认备份」，当前所有标签、你贴的标记、分的组、稍后列表，整体存成一份快照。存完去备份列表就能看到这一份。
>
> 适合你觉得当下这个状态特别重要、想单独留一份的时候用。"

**【镜头】**
- 概览页 → 点「手动备份」按钮 → 确认框 → 点「确认备份」→ 成功 toast。
- 切到备份列表 Tab → 看到新增的一份快照（高亮一下）。

**【操作】**
1. 概览页点「手动备份」→ 确认备份。
2. 切备份列表看新增快照。

### 模块三：标签导入

> 导入就是把文件里的标签还原回来。注意：导入是真的会把这些标签**重新打开**到你浏览器里，不是只存个快照。分两种用法：当前浏览器导入、跨浏览器导入。

#### 1. 当前浏览器导入

**【口播】**
> "第一种，当前浏览器导入。就是把你之前导出的文件，导回这台浏览器。
>
> 备份页切到「导入」。把 JSON 文件拖进来——它会先给你预览：多少个标签、几个窗口、哪些标记、哪些分组，一目了然。确认没问题，选「本窗口打开」或「新窗口打开」，点确认，标签就一个个打开了，标记和分组也跟着回来。
>
> 已经打开的重复标签它会自动跳过，不会重复开。"

**【镜头】**
- 备份页切「导入」Tab。
- 拖入 JSON → 预览区：标签数 / 窗口数 / 标记 / 分组列表。
- 点「本窗口打开」→ 标签一个个被打开 → 标记/分组恢复。

**【操作】**
1. 进导入页。
2. 拖入 JSON → 看预览。
3. 「本窗口打开」→ 标签恢复。

#### 2. 跨浏览器导入

**【口播】**
> "第二种，跨浏览器导入。比如你从 Chrome 换到 Edge，或者从别的标签工具迁过来。
>
> 同样在导入页，这次用 OneTab 格式——它是通用的，很多标签工具都认。把 OneTab 文本粘进来，或者导出的 JSON 文件拖进来都行，插件会自动识别格式。预览确认后打开，标签就搬到这个浏览器了。
>
> 这就是你换浏览器、换电脑时搬标签的方式。"

**【镜头】**
- 导入页切到「粘贴数据」。
- 粘一段 OneTab 文本 → 自动识别格式 → 预览。
- 「新窗口打开」→ 标签在新窗口打开。

**【操作】**
1. 导入页切粘贴数据。
2. 粘 OneTab 文本 → 识别 → 预览。
3. 「新窗口打开」→ 标签迁入。

## E11 · 快捷操作：卡片 / 右键 / 固定栏 / 编号快捷键 ｜ 高频效率 ｜ 5–7 分钟
