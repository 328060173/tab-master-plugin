## 一、通用风格规范（所有页共用，写进每个提示词开头）

```
风格：简约、大气、科技感。
版式：16:9 横版，大量留白，左右或居中对称，元素克制不堆砌。
配色：科技蓝色，主文字近白（#F5F7FA），
      高亮用电光青蓝（#3B82F6 / #38BDF8），辅助灰（#94A3B8）。
字体：中文用思源黑体/苹方 Heavy（大标题），英文/数字用 Inter 或 SF Pro，
      全大写英文做点缀。字号反差大：主标题极大，副标题小而疏朗。
装饰：细线几何（1px 青蓝描边、网格底纹、极简电路/节点线条）、
      单色渐变光晕（左上或右下角一抹青蓝辉光，不抢字）。
      禁止：花哨插画、立体阴影、彩色噪点、表情符号、过多图标。
整体气质：像一个独立开发者做的工具产品官网，冷静、可信、不喧哗。
```

## 六、每集复用流程

1. 复制「第二节·统一 3 页模板提示词」。
2. 替换 3 处占位符：`EP【0X】` 编号、封页共情大字、第 2 页主题+要点、第 3 页本期内容回顾。
3. 生成 → 导出 PNG/PPT → 套进视频开头与结尾。
4. 后续 EP03~EP13 同流程，只改字不动版式，保证整套教程视觉统一。
