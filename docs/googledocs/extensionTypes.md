### DeleteInjectionDetails

</div>

</div>

<div class="dcc-code-sections">

#### Properties

- <div>

  <div id="property-DeleteInjectionDetails-allFrames" class="dcc-code-sections__label">

  allFrames

  </div>

  <div class="dcc-type--xsmall">

  boolean <span class="dcc-code-sections__optional">optional</span>

  </div>

  </div>

  If allFrames is `true`, implies that the CSS should be removed from all frames of current page. By default, it's `false` and is only removed from the top frame. If `true` and `frameId` is set, then the code is removed from the selected frame and all of its child frames.

- <div>

  <div id="property-DeleteInjectionDetails-code" class="dcc-code-sections__label">

  code

  </div>

  <div class="dcc-type--xsmall">

  string <span class="dcc-code-sections__optional">optional</span>

  </div>

  </div>

  CSS code to remove.

- <div>

  <div id="property-DeleteInjectionDetails-cssOrigin" class="dcc-code-sections__label">

  cssOrigin

  </div>

  <div class="dcc-type--xsmall">

  [CSSOrigin](#type-CSSOrigin) <span class="dcc-code-sections__optional">optional</span>

  </div>

  </div>

  The [origin](https://www.w3.org/TR/css3-cascade/#cascading-origins) of the CSS to remove. Defaults to `"author"`.

- <div>

  <div id="property-DeleteInjectionDetails-file" class="dcc-code-sections__label">

  file

  </div>

  <div class="dcc-type--xsmall">

  string <span class="dcc-code-sections__optional">optional</span>

  </div>

  </div>

  CSS file to remove.

- <div>

  <div id="property-DeleteInjectionDetails-frameId" class="dcc-code-sections__label">

  frameId

  </div>

  <div class="dcc-type--xsmall">

  number <span class="dcc-code-sections__optional">optional</span>

  </div>

  </div>

  The [frame](https://developer.chrome.com/docs/extensions/reference/webNavigation/#frame_ids) from where the CSS should be removed. Defaults to 0 (the top-level frame).

### RunAt

<div>

<div>

<span class="dcc-tag-pill--blue dcc-tag-pill" title="Available from this Chrome version and higher">Chrome 44+ </span>

<div class="dcc-code-sections">

#### Enum

<div class="dcc-code-sections__overline dcc-code-sections__label">

<span style="white-space: nowrap;"></span>

<span class="dcc-code-sections__value">"document_start"</span>\
<span class="dcc-type--xsmall" style="white-space: initial">Script is injected after any files from css, but before any other DOM is constructed or any other script is run.</span>

<span style="white-space: nowrap;"></span>

<span class="dcc-code-sections__value">"document_end"</span>\
<span class="dcc-type--xsmall" style="white-space: initial">Script is injected immediately after the DOM is complete, but before subresources like images and frames have loaded.</span>

<span style="white-space: nowrap;"></span>

<span class="dcc-code-sections__value">"document_idle"</span>\
<span class="dcc-type--xsmall" style="white-space: initial">The browser chooses a time to inject the script between "document_end" and immediately after the `window.onload` event fires. The exact moment of injection depends on how complex the document is and how long it is taking to load, and is optimized for page load speed. Content scripts running at "document_idle" don't need to listen for the `window.onload` event; they are guaranteed to run after the DOM completes. If a script definitely needs to run after `window.onload`, the extension can check if `onload` has already fired by using the `document.readyState` property.</span>
