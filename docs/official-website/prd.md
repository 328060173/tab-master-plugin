## 1. 背景与目标

### 1.1 背景
「浏览器标签大师」是一款面向**浏览器重度使用者**的 Chrome/Edge 标签页管理扩展，已实现四视图（平铺/列表/图标/树形）、智能排序与分组、稍后处理、自定义标记、批量操作、状态感知（播放中/静音/未保存表单等）、聚焦模式、历史页（最近关闭 + 完整浏览历史）等核心能力。当前缺少一个面向用户的官网来承接：**产品介绍 / SEO 获客 / 下载安装 / 文档 / 用户反馈 / 商业化铺垫**。

### 1.2 目标
| 优先级 | 目标 | 衡量指标 |
|---|---|---|
| P0 | 品牌 + 产品介绍落地，承接「浏览器标签大师」核心信息 | 首屏 LCP < 2s，跳出率 < 50% |
| P0 | SEO 布局，抢占「浏览器标签管理 / 标签页插件」等中文搜索词 | 3 个月内核心词进前 3 页 |
| P0 | 下载转化引导（Chrome Web Store 外链 + 安装说明） | 访客→安装转化率 > 5% |
| P1 | 多产品矩阵预留（翻译/收藏/拍照大师等，当前置灰） | 导航下拉结构可扩展 |
| P1 | 用户反馈 / 沟通 / 打赏 / 预约通知闭环 | 表单提交可用 |
| P2 | 文档外链飞书，沉淀最佳实践与 FAQ | 飞书文档可访问 |

### 1.3 非目标（V1 不做）
- 不做完整后台管理系统（表单先接入免费表单服务 / 邮件 / 飞书 webhook）
- 不做多语言（V1 仅中文，i18n 后续）
- 不做用户登录账号体系（账号体系随产品后端阶段一并做）
- 不在官网内嵌插件 Demo（插件能力用截图/视频展示）

## 2. 目标用户与核心痛点

### 2.1 目标用户画像
| 画像 | 占比预估 | 特征 | 核心诉求 |
|---|---|---|---|
| 重度研究者（产品/咨询/投研分析师） | 30% | 同时开 50-200 个标签，跨多个研究课题 | 快速归类、稍后处理、找回历史标签 |
| 开发者 / 设计师 | 25% | 文档/设计稿/Issue/GitHub 标签混杂，常跨窗口 | 分组、状态感知（哪个在播放/未保存）、批量关闭 |
| 内容创作者 / 自媒体 | 15% | 选题调研打开大量素材标签 | 标记体系、稍后处理、按域名聚合 |
| 知识工作者 / 学生 | 20% | 学习资料、网课、参考文档堆积 | 树形视图、聚焦模式、历史找回 |
| 普通浏览器重度用户 | 10% | 标签越开越多但懒得管 | 一键整理、低学习成本 |

### 2.2 核心痛点（用于官网痛点区文案提炼）
1. **标签黑洞**：开了 80+ 标签，找不到刚才看的那一个，只能从头滚到尾。
2. **混乱无序**：工作/学习/娱乐混在一排，没有分组，靠记忆和运气找页面。
3. **不敢关**：怕关了找不到，明明用不到了也开着，浏览器越来越卡。
4. **跨窗口失联**：标签在不同窗口之间，Chrome 原生没有跨窗口检索，移动困难。
5. **静音播放中 / 未保存表单**：关了才发现音频还在响、表单填了一半丢了，没有状态提示。
6. **历史找回难**：Chrome 自带历史记录是一条流水账，无法按"最近关闭/今天/按站点"快速定位。
7. **重复打开**：不记得开过，又开一遍，同一个页面开 3-4 个。

### 4.6 技术性 SEO 配置
- **`cleanUrls: true`**：URL 不带 `.html`（如 `/faq` 而非 `/faq.html`），更友好。
- **`sitemap.xml`**：用 `vitepress-plugin-sitemap` 自动生成，提交百度站长 + Google Search Console + Bing。
- **`robots.txt`**：允许全部抓取，标注 sitemap 路径。
- **性能（Core Web Vitals）**：VitePress 默认 SSG 静态化，首屏 LCP 易达 < 2s；图片用 WebP + `loading="lazy"` + 声明宽高（防 CLS）；字体 `font-display: swap`。
- **内链策略**：功能区/场景区互相链接到对应文档锚点；FAQ 页面承接长尾词，互相内链。
- **百度专项**：提交百度站长平台，启用主动推送；百度对 `keywords` meta 仍有一定权重，保留。
- **TDK 模板化**：每个页面 frontmatter 写 `title` / `description`，VitePress 自动渲染 `<title>` 与 `<meta name="description">`，避免手写 HTML。

## 5. 设计系统（浅色系极简）

> 由 `ui-ux-pro-max` skill 生成方向：**Bento Grid + Apple-style 浅色极简**。参考 Cursor / Trae / Qoder / CodeBuddy 的共性——大面积留白、克制配色、几何分块、弱阴影、强内容。

### 5.1 视觉风格
- **主风格**：Bento Grid（模块化卡片网格）+ Minimalism（克制留白）。
- **气质**：专业、干净、有呼吸感、内容优先。不堆砌装饰，不用 emoji 当图标（全 Lucide SVG）。
- **明暗**：V1 仅浅色（用户明确要求「浅色系」），暗色预留 V2。

### 5.2 配色方案（已选定：信任蓝）

**选定方案：SaaS 信任蓝 —— "专业工具"心智**
| 角色 | 色值 | 用途 |
|---|---|---|
| Primary 主色 | `#2563EB`（blue-600） | 品牌色、主 CTA、激活态、logo |
| Secondary | `#3B82F6`（blue-500） | 次级按钮、hover、装饰渐变 |
| Accent 强调 | `#EA580C`（orange-600） | 下载 CTA、打赏、高亮（蓝橙对比，WCAG 3:1 达标）|
| Background 背景 | `#F8FAFC`（slate-50） | 页面底色（比纯白柔和，Apple 风）|
| Surface 卡片 | `#FFFFFF` | 卡片、悬浮面板 |
| Foreground 主文字 | `#1E293B`（slate-800） | 正文标题 |
| Muted 次文字 | `#64748B`（slate-500） | 辅助说明 |

**备选（本次不采用）：Productivity 青绿**

### 5.3 字体（中英搭配）

- **中文**：`HarmonyOS Sans SC` 或 `Noto Sans SC`（开源、屏显清晰、字重齐全）。
- **等宽（代码/数字）**：`JetBrains Mono`（版本号、统计数字用 tabular figures 防跳动）。
- **字号阶梯**（响应式 clamp）：`12 / 14 / 16 / 18 / 20 / 24 / 30 / 36 / 48 / 60 / 72`。
- **行高**：正文 1.6-1.75，标题 1.2-1.3。
- **字重层级**：H1 `700`、H2 `600-700`、H3 `600`、正文 `400`、辅助 `400 + 灰色`。
- **加载**：Google Fonts + 字重子集化，`font-display: swap`，仅预加载首屏字重。

### 5.4 间距 / 圆角 / 阴影系统
| Token | 值 | 用途 |
|---|---|---|
| `--space-1` | 4px | 图标与文字间距 |
| `--space-2` | 8px | 紧凑元素间距 |
| `--space-3` | 12px | 卡片内 padding |
| `--space-4` | 16px | 常规间距 |
| `--space-6` | 24px | 卡片内大 padding |
| `--space-8` | 32px | section 内元素组间距 |
| `--space-12` | 48px | section 间距（移动）|
| `--space-20` | 80px | section 间距（桌面）|
| `--space-32` | 128px | Hero 区上下留白 |
| `--radius-sm` | 8px | 按钮、标签 |
| `--radius-md` | 12px | 小卡片 |
| `--radius-lg` | 16-20px | Bento 大卡片（Apple 风）|
| `--radius-full` | 999px | 胶囊按钮、头像 |
| `--shadow-sm` | `0 1px 2px rgba(15,23,42,0.04)` | 卡片默认 |
| `--shadow-md` | `0 4px 16px rgba(15,23,42,0.06)` | 卡片 hover |
| `--shadow-lg` | `0 12px 32px rgba(15,23,42,0.10)` | 弹层/下拉 |

**原则**：浅色极简 = **弱阴影 + 强留白 + 清晰描边**。卡片优先用 `1px solid border + shadow-sm`，hover 升 `shadow-md` + 轻微 `translateY(-2px)`。

### 5.5 响应式断点
- 移动优先，断点：`375 / 768 / 1024 / 1440`。
- 内容最大宽度 `max-width: 1200px`（阅读区）/ `80rem`（宽展示区），居中。
- 移动端 Bento 网格降级为单列堆叠。

### Section 9：FAQ 区【H2 + 问题 H3，承接长尾 + FAQPage JSON-LD】

**布局：** 浅灰底，手风琴折叠，默认展开第 1 条。8-10 个高频问题。

**文案：**
- **H2**：`常见问题`
- **副标题**：`没找到答案？欢迎在下方反馈区联系我们。`

**FAQ 内容（10 条）：**

1. **是免费的吗？会有收费功能吗？**
   完全免费，无广告，无内购。所有核心功能（四视图、分组、标记、批量、状态感知、历史等）永久免费。未来可能推出的云同步等增值服务会单独说明，不会影响现有免费功能。

2. **支持哪些浏览器？**
   支持 Chrome 88+ 与 Edge 88+，macOS 与 Windows 均可使用。后续会评估 Firefox / Safari 支持。

3. **我的标签数据会上传到服务器吗？**
   不会。所有标签数据仅存储在你的浏览器本地（`chrome.storage.local`），不联网不上传，卸载扩展即清除。完整浏览历史仅在 YOU 主动授权后读取，同样只存在本地。

4. **装了之后浏览器会变卡吗？**
   不会。标签大师是侧边栏形态，只在 YOU 唤起时加载，平时不占用标签页资源。反而能帮你关闭冗余标签，让浏览器更流畅。

5. **能和 Chrome 原生标签分组一起用吗？**
   完全兼容。标签大师读取并管理 `chrome.tabGroups`，与原生分组无缝协作，原生分组在标签大师里直接可见可操作。

6. **固定（Pinned）标签会受影响吗？**
   不会。固定标签独立展示在 PinnedBar，不参与筛选/排序污染，与 Chrome 原生行为一致。

7. **支持跨窗口管理吗？**
   支持。跨窗口移动标签时自动监听 `onAttached/onDetached` 兜底重载，数量与浏览器实际状态始终一致。

8. **快捷键能自定义吗？**
   可以。在设置面板里修改唤起侧边栏的快捷键，也可在 Chrome 扩展快捷键设置中调整。

9. **卸载后我的数据怎么办？**
   卸载扩展会清除浏览器本地的标签大师数据。建议卸载前用"稍后处理"导出重要链接（功能开发中）。

10. **遇到 bug 或有功能建议怎么反馈？**

## 7. 技术选型：VitePress

### 7.1 为什么是 VitePress
| 维度 | VitePress | 备选（Astro / Next.js）|
|---|---|---|
| 定位 | 文档站 + 营销页，Vue 生态 | Astro 适合内容站；Next.js 过重 |
| 学习成本 | Markdown + 少量 Vue 组件 | 更高 |
| SEO | 默认 SSG 静态化，开箱即用 | 同 |
| 性能 | 极快，首屏 LCP 易 < 2s | 同 |
| 与插件栈一致 | 插件用 Vue 3，官网同栈，复用经验 | — |
| 多产品扩展 | 多路由 + 主题继承天然支持 | — |
| 部署 | 纯静态，任意静态托管免费 | — |

**结论**：VitePress 完全满足"简洁官网 + 多产品预留 + SEO + 免费部署"诉求，且与团队 Vue 技术栈一致。唯一注意点：VitePress 默认偏文档站风格，需自定义主题组件做营销页（Hero/Bento 卡片等），工作量可控。

### 7.2 项目结构（建议）
```
tab-master-website/
├─ .vitepress/
│  ├─ config.ts          # head / sitemap / nav / sidebar / cleanUrls
│  ├─ theme/
│  │  ├─ index.ts        # 自定义主题入口
│  │  ├─ components/     # Hero.vue / BentoCard.vue / ProductDropdown.vue / FAQ.vue / FeedbackForm.vue / Donate.vue / WeChatGroup.vue
│  │  └─ styles/         # tokens.css（配色/间距/字体变量）
│  └─ scripts/           # JSON-LD 注入、表单 webhook
├─ index.md              # 首页（用自定义组件布局）
├─ products/
│  ├─ tab-master.md      # = 首页内容（或重定向）
│  ├─ translate-master.md
│  ├─ favorite-master.md
│  └─ photo-master.md
├─ faq.md
├─ changelog.md
├─ about.md
├─ contact.md
├─ public/
│  ├─ og/                # Open Graph 封面
│  ├─ screenshots/       # 功能截图
│  ├─ qr/                # 打赏/微信群二维码
│  └─ logo.svg
└─ package.json
```

### 7.3 关键配置示例
- `cleanUrls: true`
- `sitemap` 插件自动生成
- `head` 注入 §4.1 全站 meta
- 首页 `index.md` 用 frontmatter 写 `title` / `description`，正文用 `<Hero />` `<BentoGrid />` 等 Vue 组件布局
- JSON-LD 通过自定义组件在 `<ClientOnly>` 内注入，或直接在 config head 写静态版本
