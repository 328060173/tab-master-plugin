## 3. Detailed Description（商店详情页，约 1800 字）

```
开了几十个标签找不到刚才那个？关了又怕找不回？标签栏挤成一排越用越乱？

3 秒找到任何标签，标签再多也不乱——TM-浏览器标签整理大师是一款专为浏览器重度用户设计的侧边栏标签管理插件。它常驻在浏览器侧边，不占用标签栏位置，让你用最顺手的方式管理所有标签页，告别标签混乱。

【为什么选择标签整理大师】

■ 3 秒找回任何标签
实时搜索标签标题、网址、域名，命中高亮，分"固定 / 已打开 / 最近关闭"三段展示，配合"最近访问优先"排序，常用标签永远在最前。再给 4 个最常用的标签设上编号，按 Alt+Shift+1~4 全局快捷键瞬间切换，不用再在标签栏里一个个找。

■ 四视图随心切换
平铺看全貌、列表看详情、图标省空间、树形看父子层级。同一组标签四种看法，怎么顺手怎么看。树形视图自动推断标签的打开来源关系，把同源标签归到一棵树里。

■ 聚焦模式，专注不被打断
写文档、写代码时，其他标签总是分散注意力。开启聚焦模式，选中你要用的几个标签，其余自动折叠到"已隐藏"分组里，眼前只剩当前任务。新开标签自动加入聚焦，关掉最后一个自动退出，展开隐藏分组还会自动重新折叠——全程不打断你的思路。

■ 标记分类，给标签贴标签
自定义文本标记（工作、待读、重要、今天要处理……），最多 15 个，可拖动排序。给标签贴上标记后，点一下标记栏就能筛出同类标签。卡片、悬停卡、右键菜单、批量工具栏，五个入口都能贴标，怎么方便怎么来。

■ 状态感知，关之前提醒你
正在播放音乐、正在录屏、正在共享屏幕、连接着外部设备——这些标签关了会出问题。标签整理大师自动识别 5 种活动状态，在卡片上亮起徽章，关闭危险操作还会二次确认，避免误关。

■ 稍后处理，不丢也不乱
暂时不看、之后要用的标签，存到"稍后处理"列表里并关掉腾空间，还能加备注。最近关闭的 50 个标签自动收进列表，一键恢复。需要更早的记录？申请浏览历史权限（可选，随时可关），查看最近 7 天完整历史，按时间或站点分组，还能单条删除。

■ 智能整理，一键清理
"整理"菜单帮你检测重复标签（同一个网址开了好几个）、检测长期未用的标签（1/3/7/30 天阈值可自定义），弹预览让你勾选关闭，浏览器卡顿一扫而空。

■ 域名归并，同站聚一起
按注册域名归并排序，github.com、console.github.com、buy.github.com 自动聚到一起，50 个同站标签不再散落各处。还把常见站点显示成中文名（如把云厂商控制台显示成品牌名），更易认。

■ 备份与导入导出，崩溃也不怕
一键把所有标签、标记、分组、稍后处理列表备份成文件，浏览器崩溃、误关、重装系统都不怕丢。支持导出标准 JSON（可完整恢复）、Markdown（人类可读）、OneTab 兼容格式。换浏览器、换电脑？导入备份文件即可还原全部标签与分类，跨 Chrome/Edge 随时恢复，标签再也不会凭空消失。

■ 装扮你的侧边栏
登录后可用积分兑换头像框、主题背景图、纯色背景，给侧边栏换个心情。未购买可试穿 30 秒预览效果。

【适合谁用】

· 投研分析师：同时盯几十个行情、研报、数据源标签，需要快速切换和分组
· 开发者：文档、代码仓库、控制台、Issue 一开一大堆，树形视图看清来源关系
· 内容创作者：素材、参考、草稿标签堆成山，标记分类 + 稍后处理慢慢消化
· 学生：网课、资料、笔记标签混在一起，按域名归并 + 聚焦模式专心学习
· 任何标签开太多的人：3 秒找到、一键整理、不怕误关

【更多细节】

· 常驻侧边栏形态，不占标签栏位置，比"新标签页"类工具更顺手
· 明暗模式 + 字号设置，跟随系统或手动切换
· 每个区域独立错误降级，一处出问题不影响其他功能
· 支持中英文界面
· 数据安全：浏览历史、标签信息仅存本机，绝不上传；登录账号用于积分与装扮同步

【支持平台】

Windows / macOS × Chrome / Edge 四端通用。
需 Chrome / Edge 114 及以上（侧边栏功能所需）；标签分组需 89+；"最近访问排序"在 121+ 上效果最佳，低版本自动回退。

让标签整理大师帮你把标签管起来，把注意力留给真正重要的事。
```

## 6. 权限说明（上架表单 / 详细描述附录，逐权限说明用途）

| 权限 | 用途 |
|---|---|
| `tabs` | 读取与管理浏览器标签页（列表、切换、关闭、搜索、排序、编号、状态感知） |
| `tabGroups` | 创建与管理标签分组、聚焦模式折叠分组（需 Chrome/Edge 89+） |
| `storage` | 本地保存用户设置、标记、稍后处理列表、登录态等 |
| `sidePanel` | 以浏览器侧边栏形态常驻展示主界面（需 Chrome/Edge 114+） |
| `alarms` | 后台定时拉取通知、版本检查、广告缓存（定时器） |
| `history`（可选） | 查看完整浏览历史。**可选权限**，仅当用户主动开启时才申请，可随时关闭 |
| `host_permissions: api.ouu365.com` | 调用后端接口（登录、反馈、版本检查、道具商城） |
| `host_permissions: www.ouu365.com` | 跳转官网页面（反馈、隐私政策、帮助文档） |

> 不申请全网域（`*://*/*`）权限，仅访问自有后端与官网。

## 7. 数据使用声明（Data Use，上架表单如实勾选）

插件在用户登录后会上传以下数据到自有后端 `api.ouu365.com`（用于账号、积分、装扮同步）：

| 数据 | 用途 | 是否必需 |
|---|---|---|
| 邮箱地址 | 邮箱验证码登录（登录即注册） | 登录时必需，不登录可不提供 |
| 设备信息（浏览器、操作系统、语言） | 版本灰度判断、设备记录 | 调用版本检查接口时携带 |
| 反馈内容 | 用户主动提交的意见反馈 | 用户主动提交时 |
| 账号信息（积分、性别） | 积分体系、头像配色 | 登录后 |

**绝不上传**：浏览历史、标签网址与标题、标签分组内容——这些仅存本机。

## 8. 跨端兼容声明

| 平台 | 支持 | 备注 |
|---|---|---|
| Windows + Chrome | ✅ | Chrome 114+ |
| Windows + Edge | ✅ | Edge 114+ |

关键 API 最低版本要求（代码注释同步标注）：

| API | 最低版本 | 用途 | 低版本处理 |
|---|---|---|---|
| `chrome.sidePanel` | Chrome/Edge 114+ | 侧边栏主界面 | 不支持则无法使用核心形态 |
| `chrome.sidePanel.getLayout` | Chrome/Edge 140+ | 读取侧边栏位置（左/右） | 有回退，不影响主功能 |
| `chrome.tabGroups` | Chrome/Edge 89+ | 标签分组、聚焦模式 | 不支持时分组相关功能降级 |
| `chrome.tabs.Tab.lastAccessed` | Chrome/Edge 121+ | "最近访问优先"排序 | 回退到打开时间排序 |
| `chrome.tabs` / `storage` / `alarms` / `history` | 通用 | 基础功能 | — |

快捷键 `Alt+Shift+1~4` 全端一致（Mac/Win 通用）；如与其他扩展冲突，用户可在 `chrome://extensions/shortcuts` 自定义。
