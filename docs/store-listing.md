## 3. Detailed Description（商店详情页）

```
浏览器标签大师是一款浏览器标签管理、备份与恢复工具，帮你搜索、整理、保存和恢复标签页。标签太多找不到？下班又不敢直接关浏览器？一键备份所有标签，下次打开随时还原；开了几十个网页，3秒搜索定位，不再翻来翻去；重复和长期不用的标签一键清理。

核心功能

💾 标签备份与恢复：下班了，终于敢直接关浏览器
工作结束后，不需要让几十个工作标签继续开着。点击「标签导入导出」，把标签、标记、分组和稍后处理列表保存成文件，然后直接关闭浏览器。第二天打开浏览器后导入备份，一键恢复原来的工作状态。支持标准 JSON（完整还原全部状态）、Markdown（人可读）、OneTab 兼容格式（可导入其他工具）。换电脑、换浏览器，导入备份文件即可恢复。即使遇到浏览器异常关闭，也可以通过已有备份恢复。

🔎 标签搜索：开了50个网页，3秒找到
侧边栏顶部搜索框，输入关键词实时匹配标题、网址、域名，命中高亮，分「固定 / 已打开 / 最近关闭」三段展示。配合「最近访问优先」排序，常用标签永远在最前。给4个最常用的标签设编号，按 Alt+Shift+1~4 全局快捷键瞬间切换。

🧹 标签整理：重复的、长期不用的，一键清掉
「整理」菜单自动检测重复标签（同一个网址开了好几个）和长期未用的标签（1/3/7/30 天阈值可自定义），弹预览让你勾选关闭，浏览器标签再多也能快速清理，让侧边栏清爽不卡。

🗂️ 域名归并与标记分类：同站聚一起，给标签贴标签
按注册域名归并排序，github.com、console.github.com 自动聚到一起，50个同站标签不再散落。常见站点显示为中文名。自定义文本标记（工作、待读、重要、今天要处理等），最多15个，可拖动排序，点标记栏一键筛选。

👁️ 四视图随心切换：平铺、列表、图标、树形
平铺看全貌、列表看详情、图标省空间、树形看父子层级。树形视图自动推断标签的打开来源关系，看清「这个标签是从哪个链接点开的」。

🎯 聚焦模式：专注不被打断
开启聚焦模式，选中你要用的几个标签，其余自动折叠到「已隐藏」分组，眼前只剩当前任务。新开标签自动加入聚焦，关掉最后一个自动退出。

↩️ 最近关闭与稍后处理：不丢也不乱
最近关闭的50个标签自动收进列表，一键恢复。暂时不看的标签加入「稍后处理」列表，关掉腾空间，还能加备注。

⚠️ 状态徽章与防误关
自动识别播放中、静音、录制中、共享中、连接设备5种状态，关闭危险标签弹二次确认，防止手滑。

🎨 个性化装扮
登录后可用积分兑换头像框、主题背景图、纯色背景。

数据只存你电脑，不外传
浏览历史、标签网址和标题、分组内容、标记列表——只存本机，绝不上传。登录账号只用于积分和装扮同步，不偷看标签，也不做云端标签同步。公司署名「遨游365」。

适合谁用
· 上班族/知识工作者：下班了敢直接关浏览器，不怕明天找不到
· 开发者：文档、代码仓库、控制台一开一大堆，搜索定位、树形视图看清来源
· 内容创作者：素材、参考、草稿标签堆成山，标记分类 + 稍后处理慢慢消化
· 学生：网课、资料、笔记标签混在一起，域名归并 + 聚焦模式专心学习
· 任何标签开太多的人：3秒找到、一键整理、不怕关闭

更多细节
· 常驻侧边栏形态，不占标签栏位置
· 明暗模式 + 字号设置，跟随系统或手动切换
· 支持中英文界面

支持平台
Windows / macOS × Chrome / Edge 四端通用。
需 Chrome / Edge 114 及以上（侧边栏 sidePanel API 所需）；标签分组需 89+；「最近访问排序」在 121+ 上效果最佳。

怎么装、怎么用

在 Edge Add-ons 搜「浏览器标签大师」，点安装。

装完点浏览器右上角扩展图标，打开侧边栏。

先点「标签导入导出」做第一次备份，给标签上份保险。

以后想找标签就在侧边栏搜索框输入关键词；想整理点「整理」菜单；想专注开聚焦模式；想分类贴标记。

核心功能免费——把标签管起来，把注意力留给真正重要的事。
```

## 6. 权限说明（上架表单 / 详细描述附录，逐权限说明用途）

| 权限 | 用途 |
|---|---|
| `tabs` | 读取与管理浏览器标签页（列表、切换、关闭、搜索、排序、编号、状态感知） |
| `tabGroups` | 创建与管理标签分组、聚焦模式折叠分组（需 Chrome/Edge 89+） |
| `storage` | 本地保存用户设置、标记、稍后处理列表、登录态等 |
| `sidePanel` | 以浏览器侧边栏形态常驻展示主界面（需 Chrome/Edge 114+） |
| `alarms` | 后台定时拉取通知、版本检查、广告缓存（定时器） |
| `history`（可选） | 查看完整浏览历史。**可选权限**，仅当用户主动开启时才申请，可随时关闭 |
| `host_permissions: api.ouu365.com` | 调用后端接口（登录、反馈、版本检查、道具商城） |
| `host_permissions: www.ouu365.com` | 跳转官网页面（反馈、隐私政策、帮助文档） |

> 不申请全网域（`*://*/*`）权限，仅访问自有后端与官网。

## 7. 数据使用声明（Data Use，上架表单如实勾选）

插件在用户登录后会上传以下数据到自有后端 `api.ouu365.com`（用于账号、积分、装扮同步）：

| 数据 | 用途 | 是否必需 |
|---|---|---|
| 邮箱地址 | 邮箱验证码登录（登录即注册） | 登录时必需，不登录可不提供 |
| 设备信息（浏览器、操作系统、语言） | 版本灰度判断、设备记录 | 调用版本检查接口时携带 |
| 反馈内容 | 用户主动提交的意见反馈 | 用户主动提交时 |
| 账号信息（积分、性别） | 积分体系、头像配色 | 登录后 |

**绝不上传**：浏览历史、标签网址与标题、标签分组内容——这些仅存本机。

关键 API 最低版本要求（代码注释同步标注）：

| API | 最低版本 | 用途 | 低版本处理 |
|---|---|---|---|
| `chrome.sidePanel` | Chrome/Edge 114+ | 侧边栏主界面 | 不支持则无法使用核心形态 |
| `chrome.sidePanel.getLayout` | Chrome/Edge 140+ | 读取侧边栏位置（左/右） | 有回退，不影响主功能 |
| `chrome.tabGroups` | Chrome/Edge 89+ | 标签分组、聚焦模式 | 不支持时分组相关功能降级 |
| `chrome.tabs.Tab.lastAccessed` | Chrome/Edge 121+ | "最近访问优先"排序 | 回退到打开时间排序 |
| `chrome.tabs` / `storage` / `alarms` / `history` | 通用 | 基础功能 | — |

快捷键 `Alt+Shift+1~4` 全端一致（Mac/Win 通用）；如与其他扩展冲突，用户可在 `chrome://extensions/shortcuts` 自定义。
