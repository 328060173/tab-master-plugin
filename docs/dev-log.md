## 2026-08-17 · E02 教程脚本按新结构重写 + v1.4.1 实测校正

**产出**：`docs/video-script.md` E02 段重写（+170 / −55 行）

**背景**：用户明天要录「标签备份、标签导入导出」这集，要求按新思路重新组织：先简短介绍需求痛点 → 三大模块功能演示 → 最后最佳实践。语言简单精炼。

**新结构**（按用户指定）：
1. **开场痛点**——最怕的不是标签多，而是突然没了（简短）
2. **模块一 标签备份**：①自动监听备份【重点】②自动定时备份 ③手动备份
3. **模块二 标签导出**：①导出当前 ②导出备份（+ JSON/Markdown/OneTab 三格式）
4. **模块三 标签导入**：①当前浏览器导入 ②跨浏览器导入
5. **最佳实践**：①快速下班（开自动监听→关浏览器→次日还原，随时敢关电脑）②跨浏览器搬标签（公司↔家）

每个小节补齐【口播】+【镜头】+【操作】三段。

**关键校正（旧脚本与 v1.4.1 实测不符，派 Explore agent 核对代码后修正）**：
- **频率选项 = 10/15/30/60 分钟**（旧写 1/3/5/10/30，错）。默认 10 分钟。定时器在 **Service Worker** 跑（`chrome.alarms`），侧边栏关着也存。
- **只有一个「自动监听备份」开关**（`listenBackupEnabled`），统一 **500ms 防抖**，监听 `onCreated/onUpdated/onRemoved/onWindowCreated/onWindowRemoved` 全量 `chrome.tabs.query` 存活档。旧脚本写的"标签关闭后/窗口关闭后/空闲时"四个开关是**已废弃的旧方案**（`eventOnWindowRemoved` 注释标"虚假已废弃"，MV3 SW 30s 休眠关浏览器来不及写完）——已删。
- **手动备份按钮文案 = 「手动备份」**，确认按钮 **「确认备份」**（旧写"立即备份"，错）。
- **导出分两个入口**：概览页「导出」= 导出当前标签（实时 query）；备份列表行「导出」= 导出某份快照。旧脚本没区分清楚。
- **导入/还原真的 `chrome.tabs.create` 打开标签**（不是只存快照），重复 URL 自动跳过，预览含标签数/窗口数/标记/分组。旧脚本没点明"会重新打开"。
- **快速下班次日恢复路径**：`onStartup` 自动封存昨晚活档为历史档 → 备份列表找监听档（source=`auto.listen`）→ 点「还原 ▾」→ 本窗口/新窗口打开。旧脚本没说清怎么找回。

## 2026-08-15 · Bilibili 官方教程脚本

**产出**：`docs/video-script.md`（1080 行，13 集教程系列脚本）

**背景**：用户要录 B 站教程视频，逐集介绍插件功能。本日产出可录制终稿。

**核心设计**（经多轮反馈迭代定稿）：
- **教程主线 + 场景演示**，非推广。独立开发者本人讲课口吻（"我自己做的一个插件"）。
- **学习曲线排序**（非功能目录）：E01 是谁/为什么 → E02 先保护标签（备份提前，建立安全感）→ E03 找 → E04 分类 → E05 看 → E06 专注 → E07 项目管理 → E08 临时收纳 → E09 找回 → E10 防误关 → E11 提效 → E12 辅助 → E13 个性化
- **每集统一结构**：固定开场（"大家好，我是 xpd，今天给大家介绍一下我自己做的一个插件——浏览器标签大师……"）→ 第一人称具体痛点 → 逐步操作 → 一个完整示例 → 固定结尾（"我会根据大家的反馈继续改"）→ 片尾「0X / 13」
- **痛点写法**：写"我今天碰到的具体问题"，不写广告腔行业痛点
- **时长**：5–10 分钟是上限不是目标，能 5 分钟讲清绝不凑 10 分钟

**13 集清单**：
| 集号 | 主题 | 定位 | 时长 |
|---|---|---|---|
| E01 | 标签大师是什么 + 安装 + 第一次使用 | 入门 | 6–8 min |
| E02 | 备份、导入导出、自动监听 | 核心安全 | 8–10 min |
| E03 | 搜索 | 高频使用 | 4–6 min |
| E04 | 标记分类（A/B 项目一键筛） | 分类 | 5–7 min |
| E05 | 四视图 + 排序 + 域名归并 | 整理 | 6–8 min |
| E06 | 聚焦模式 | 专注 | 4–6 min |
| E07 | 分组 | 项目管理 | 4–6 min |
| E08 | 稍后处理 | 临时收纳 | 3–5 min |
| E09 | 历史 / 最近关闭 | 找回 | 3–5 min |
| E10 | 状态感知 | 防误操作 | 5–7 min |
| E11 | 卡片/右键/固定栏/编号快捷键 | 高频效率 | 5–7 min |
| E12 | 小工具 | 辅助能力 | 3–5 min |
| E13 | 设置与装扮 | 个性化 | 3–5 min |

**关键文案核对（以 v1.4.1 代码实测为准，不凭旧文档）**：
- **E10 状态徽章 = 6 种**（`lib/statusConfig.ts`）：播放中 / 已静音 / 录制中 / 共享中 / 连接设备 / 引起注意（attention 在 `useTabStats.ts` 统计中被使用，会真正激活）。脚本曾误写 5 种且漏 muted，已修正。
- **E11 快捷键分平台**（`lib/platform.ts` 的 `shortcutHint`）：Win = `Alt+Shift+1~4`，Mac = `Option(⌥)+Shift(⇧)+1~4`（Option 即 Alt）。不强行说"一样"。
- **E02 换电脑表述**：明确"导出备份文件带到新电脑再导入，工作状态迁过去"，**不暗示云同步**（红线）。
- **E05 树形视图**：按标签打开关系显示父子层级，不暗示"理解项目层级"。
- **E08 稍后处理 vs 最近关闭**：两个心智——主动"以后再看" vs 手滑误关（最近关闭在历史页，不在稍后页）。
- **E01 核心理念字幕**：「先保护工作状态，再慢慢整理标签」（比"标签管理工具"高级，是产品差异化定位）。

**运营复用设计**：
- 13 集是产品教程基础设施，录完从原始素材剪短视频多渠道分发（B站/小红书/抖音/朋友圈/公众号）。
- 附录 D 素材池：从 E02 剪《浏览器崩溃了怎么办》《下班前为什么备份》《换电脑怎么带标签》等；同一功能可出现在不同短视频，表达方式不同（教程讲功能怎么用，短视频讲什么时候用），不重复。
- 附录 E：官网"官方视频教程"导航结构（01–13），B 站成播放列表、官网成导航闭环。

**录制策略**：先录 E01+E02+E03 看回放，问三个问题（像不像真人讲 / 新手能不能照做 / 有没有 PM 自嗨用户听不懂的话），再批量录 E04–E13。

**待办**：用户实机验证后开录。
