# 批量选择工具栏重构

> Status: Draft · Author: product-manager · Date: 2026-06-29

## 1. 用户场景与痛点

### 场景1：调研后清理
> 产品经理调研竞品，打开了50个标签页，分属10个域名。调研结束后，想保留每个域名下最重要的2-3个标签，关闭其余的。
>
> 痛点：当前批量模式隐藏了卡片右侧按钮，无法在批量过程中快速预览单条标签内容，也无法临时单条操作；整屏蓝色调干扰注意力。

### 场景2：批量归档
> 全栈工程师完成一个项目迭代，想把30个相关标签一次性加入「项目v1.0」分组，同时给其中10个打「待回顾」标记。
>
> 痛点：当前批量按钮有蓝色边框，视觉上跟其他按钮割裂；没有下拉菜单，需要额外的底部操作栏，占用垂直空间。

### 场景3：聚焦模式混淆
> 设计师开启聚焦模式选择标签，发现批量按钮自动变成了「取消批量」，但自己根本没进批量模式，感到困惑。
>
> 痛点：聚焦模式和批量模式的状态互相污染，用户心智模型混乱。

## 2. 竞品分析

### Chrome 自带「选择多个标签」
- 右键标签 →「选择多个标签」，进入后每个标签左侧出现圆形 checkbox
- 顶部出现固定操作栏：全选 / 取消选择 / 添加到新组 / 加入书签 / 关闭
- 特点：极简，只保留最核心操作，不改变卡片原有布局

### Tab Wrangler
- 列表模式下每个标签自带 checkbox，无需「进入批量」的切换
- 顶部有批量操作栏：关闭选中 / 锁定选中 / 排除选中
- 特点：常驻 checkbox，降低操作门槛，但视觉上稍显杂乱

### Tab Manager Plus
- 点击「Bulk Select」按钮进入批量模式，按钮文字变成「Done」
- 每个卡片左上角出现 checkbox，卡片其他元素完全保留
- 顶部下拉菜单提供：全选 / 反选 / 关闭 / 移动到窗口 / 加入分组
- 特点：明确的「进入/退出」状态，保留卡片原有功能，操作集中在下拉菜单

## 3. 核心交互流程

### 进入批量
1. 用户点击工具栏「批量」按钮
2. 系统反馈：
   - 所有非固定标签左侧出现 checkbox
   - 批量按钮文字变为「取消批量」
   - 批量按钮变为可展开的下拉触发器
   - 其他工具栏按钮（视图/排序/清理）保持不变

### 选择标签
3. 用户点击 checkbox 选中/取消标签
4. 系统反馈：
   - checkbox 实时更新选中状态
   - 下拉菜单中「关闭 N 个」的 N 随选中数变化
   - 支持点击单个 checkbox 或通过下拉菜单全选/反选

### 批量操作
5. 用户点击「取消批量」按钮展开下拉菜单
6. 系统显示：
   - 选择操作（全选、反选）
   - 批量动作（关闭 N 个、加入稍后、加入分组、添加标记）
7. 用户选择一个动作
8. 系统执行动作并给出 toast 反馈
9. 默认动作（关闭/加入稍后/加入分组）执行后自动退出批量模式；添加标记后保留批量模式

### 退出批量
10. 用户点击「取消批量」按钮或点击下拉菜单外区域
11. 系统反馈：
    - 隐藏所有 checkbox
    - 清空选中状态
    - 批量按钮文字变回「批量」
    - 下拉菜单收起

## 4. UI 描述

### 批量按钮
- 视觉规范：跟视图/排序/清理按钮完全一致
  - 默认态：`border-gray-200`、`hover:bg-gray-50`、无蓝色边框
  - 激活态（批量模式中）：`bg-blue-50`、`border-blue-300`、`text-blue-700`
- 图标：默认 `CheckSquare`，批量模式中 `XSquare`
- 文案：默认「批量」，批量模式中「取消批量」
- 交互：点击按钮展开/收起下拉菜单（跟视图/排序/清理一致）

### 批量下拉菜单
- 位置：按钮下方左对齐
- 宽度：`w-48`（192px）
- 项目顺序：
  ```
  选择
    全选可见
    反选
  ─────────
  操作
    关闭 {N} 个
    加入稍后处理
    加入分组
      新建分组...
      ────
      {现有分组列表}
    添加标记
      {现有标记列表}
      新建标记...
  ```
- 禁用态：未选中任何标签时，「关闭 N 个」「加入稍后」「加入分组」「添加标记」置灰 disabled

### Checkbox 位置
- 列表视图：favicon 左侧，`w-4 h-4`，`accent-blue-600`
- 平铺视图：卡片左上角，favicon 上方
- 图标视图：图标左下角
- 树形视图：节点缩进前

### 卡片其他元素
- **保留**：favicon、标题、域名、分组徽章、标记、右侧操作按钮（复制/标记/稍后/更多/关闭）
- **隐藏**：hover 卡片（避免干扰批量选择）
- **交互**：整张卡片点击 = 激活标签（不变），不触发选中；只有点击 checkbox 才切换选中

## 5. 边界条件

### 未选中任何标签
- 下拉菜单中「关闭 N 个」显示「关闭 0 个」并置灰 disabled
- 「加入稍后处理」「加入分组」「添加标记」同样置灰 disabled

### 切换视图
- 选中状态**保留**，checkbox 在新视图中重新渲染
- 例：在列表视图选了5个标签，切到平铺视图，这5个标签仍处于选中状态

### 切换导航 tab
- 切到「稍后」「分组」「历史」时，**自动退出批量模式**并清空选中
- 理由：批量操作仅针对「首页」的普通标签

### 聚焦模式
- 聚焦选择态（`focusMode === 'selecting'`）下，批量按钮**置灰 disabled**
- 聚焦进行态（`focusMode === 'focusing'`）下，批量按钮**隐藏**
- 明确隔离：聚焦模式和批量模式互斥，避免状态污染

### 右键菜单
- 批量模式中右键单条卡片，**显示普通右键菜单**（不变）
- 理由：用户可能需要在批量过程中临时单条操作

### 固定标签
- 固定标签**不显示** checkbox，不参与批量操作
- 理由：固定标签通常是常用标签，不应该被批量关闭/移动

## 6. 文案规范

### 按钮与菜单
- 批量按钮默认：「批量」
- 批量按钮激活：「取消批量」
- 下拉分组标题：「选择」「操作」
- 全选：「全选可见」
- 反选：「反选」
- 关闭：「关闭 {N} 个」
- 加入稍后：「加入稍后处理」
- 加入分组：「加入分组」
- 新建分组：「新建分组...」
- 添加标记：「添加标记」
- 新建标记：「新建标记...」

### Toast 反馈
- 进入批量并预选：「已选中 {N} 个标签」
- 关闭：「已关闭 {N} 个标签」
- 加入稍后：「已加入稍后处理（{N}）」
- 加入分组：「已加入分组（{N}）」
- 新建分组：「已新建分组「{name}」（{N}）」
- 添加标记：「已为 {N} 个标签加 {M} 个标记」

### Tooltip
- 批量按钮默认：「批量选择标签」
- 批量按钮激活：「退出批量模式」
- checkbox：无 tooltip

## 7. 不做的事

### 不做：键盘 Shift/Cmd 多选
- 理由：当前需求仅涉及基础的 checkbox 交互，键盘快捷键是锦上添花，后续迭代再考虑

### 不做：长按卡片进入批量
- 理由：侧边栏空间有限，长按容易与滚动/拖拽混淆，且已有明确的按钮入口

### 不做：撤销批量动作
- 理由：关闭标签用户可通过 `Ctrl+Shift+T` 恢复，其他操作影响不大，暂不做专门的撤销

### 不做：底部固定操作栏
- 理由：用户明确要求用下拉菜单替代底部栏，释放垂直空间

### 不做：整卡点击切换选中
- 理由：用户明确要求保留卡片原有交互（点击激活标签），仅通过 checkbox 选择

## 8. 验收清单

### 功能验收
- [ ] 点击「批量」按钮进入批量模式，按钮文字变为「取消批量」，无蓝色边框
- [ ] 批量模式中，所有非固定标签左侧出现 checkbox
- [ ] 点击 checkbox 切换选中状态，选中状态视觉清晰
- [ ] 点击「取消批量」按钮展开下拉菜单，包含「选择」和「操作」分组
- [ ] 「全选可见」点击后选中当前视图的所有非固定标签
- [ ] 「反选」点击后反转当前视图的选中状态
- [ ] 未选中任何标签时，操作项置灰 disabled
- [ ] 「关闭 N 个」点击后关闭选中标签，显示 toast，自动退出批量
- [ ] 「加入稍后处理」点击后将选中标签加入稍后，显示 toast，自动退出批量
- [ ] 「加入分组」子菜单包含「新建分组...」和现有分组列表
- [ ] 「添加标记」子菜单包含现有标记和「新建标记...」
- [ ] 「添加标记」执行后保留批量模式，不自动退出
- [ ] 切换视图（平铺/列表/图标/树形）时，选中状态保留
- [ ] 切换到「稍后」「分组」「历史」导航 tab 时，自动退出批量并清空选中
- [ ] 聚焦选择态下，批量按钮置灰 disabled
- [ ] 聚焦进行态下，批量按钮隐藏
- [ ] 卡片右侧操作按钮（复制/标记/稍后/更多/关闭）在批量模式中保留并可点击
- [ ] 点击「取消批量」按钮或下拉菜单外区域，退出批量并清空选中

### 视觉验收
- [ ] 批量按钮与视图/排序/清理按钮视觉一致，无特殊样式
- [ ] checkbox 大小适中，位置合理，不遮挡卡片内容
- [ ] 下拉菜单样式与其他工具栏下拉一致
- [ ] 无整屏蓝色调，无卡片蓝色背景（除非用户手动选中）

### 交互验收
- [ ] 聚焦模式不影响批量按钮状态，两者完全隔离
- [ ] 整卡点击仍激活标签，不触发选中
- [ ] 只有点击 checkbox 才切换选中状态

## 9. 风险与未决问题

### 已知风险
- 树形视图的 checkbox 缩进可能需要额外调整布局
- 标记选择器在批量模式下的复用需要确认交互一致性

### 未决问题
- 批量模式中是否需要支持「点击标签页外部区域退出批量」？（建议：是）
- 是否需要记住用户上次退出批量时的选中状态？（建议：否，每次重新进入清空）
