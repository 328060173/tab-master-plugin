# 浏览器标签大师 · 功能使用文档

> 本文档介绍「浏览器标签大师」侧边栏插件的核心功能与使用方法。按「大功能 → 小功能 → 操作项」逐层展开；操作项过多的菜单只给概述，便于快速了解全貌。

---

## 〇、概述

「浏览器标签大师」是一款浏览器侧边栏标签管理工具，帮助用户在侧边栏内高效查看、整理、搜索和标记当前窗口的所有标签页。

- **运行环境**：Chrome / Edge，支持 macOS / Windows。
- **主界面总览**：侧边栏自上而下分为四个区域——顶部导航、工具栏、内容区、底部状态栏。

## 一、顶部导航

侧边栏顶部提供四个一级页签，点击切换不同功能页。

### 1.1 页签切换

| 页签 | 作用 |
|---|---|
| 首页 | 标签管理主战场，查看/搜索/标记/整理当前窗口标签 |
| 稍后处理 | 临时存放待稍后查看的标签 |
| 分组 | 按分组查看与管理标签 |
| 历史 | 查看最近关闭与浏览历史 |

- 「稍后处理」页签在有内容时会显示未处理数量角标。

📌【配图2】顶部导航条截图

### 1.2 首页竖三点菜单

仅在「首页」页签下出现，紧贴「首页」文字右侧。提供首页常用显示项的快捷开关与设置入口（具体子项以实际版本为准，一般含：显示/隐藏搜索栏、显示/隐藏标记栏、进入聚焦模式、打开设置等）。

## 二、首页

标签管理的核心页面。

### 2.1 搜索

- 实时搜索当前窗口的标签页，匹配标题、URL、域名，支持拼音。
- 保留搜索历史，可快速复用与清空。
- 搜索结果独立展示在内容区上方。

📌【配图3】搜索框 + 搜索结果区

### 2.2 标记栏（TagBar）

给标签打自定义标记，便于分类与筛选。

- **新建标记**：在标记栏新建自定义标记。
- **管理标记**：重命名、删除、拖动排序（有数量上限）。
- **标记筛选**：点击标记筛选出带有该标记的标签，支持单选/多选模式切换。

📌【配图4】标记栏 + 标记管理下拉面板

### 2.3 工具栏

工具栏集中了视图切换、排序与批量整理操作。

- **视图切换**：提供四种标签展示视图——
  - 列表视图（默认，竖向列表）
  - 平铺视图（卡片网格）
  - 图标视图（仅图标紧凑排列）
  - 树形视图（按父子层级展示，限 5 层）
- **排序方式**：按域名归并、最新访问优先、按打开时间正序/倒序等。
- **批量选择**：进入选择态后可对多个标签批量操作（加入稍后、加入分组、关闭等）。
- **整理菜单**：一键检测长期未使用的标签、批量清理等。危险操作（如关闭）会标红并二次确认。

📌【配图5】工具栏 + 视图切换 + 排序下拉

### 2.4 固定标签栏（PinnedBar）

浏览器固定的标签页单独展示在顶部固定栏，支持拖动重新排序。

📌【配图6】固定标签栏

### 2.5 标签卡片与悬停操作

- 每个标签卡片展示：网站图标、标题、编号、标记、分组色。
- 鼠标悬停时浮出快捷操作卡，可快速关闭、固定、添加标记等。

📌【配图7】单标签卡片 + 悬停快捷操作

### 2.6 右键菜单（概述）

在任意标签卡片上右键，唤起完整的单标签操作菜单。功能较多，此处仅归类概述：

- **基础操作**：刷新、复制标签页、固定/取消固定、静音/取消静音。
- **分组**：移到分组（含新建分组、移出分组、选择同分组标签）。
- **标记**：添加标记。
- **链接**：复制 URL。
- **关闭**：关闭标签页、关闭其他标签页、关闭右侧标签页等。

> 子项随标签当前状态（是否已固定、是否在分组内等）动态显示，不一一列举。

## 三、聚焦模式

### 3.1 什么是聚焦模式

进入聚焦模式后，非聚焦的分组会被折叠，突出当前工作区，减少干扰。适合集中注意力处理一组标签时使用。

### 3.2 进入与退出

- 可在首页选择若干标签后进入聚焦。
- 聚焦态下全屏黑罩覆盖，屏幕中央显示醒目的「关闭聚焦」按钮，点击即可退出（类似屏幕共享的样式）。

## 四、稍后处理

### 4.1 加入稍后

通过右键菜单、拖入或其他快捷方式，将标签加入「稍后处理」列表，暂存待后续查看。

### 4.2 稍后列表管理

- 在「稍后处理」页查看全部暂存标签。
- 可逐个打开、移除，或批量操作。

📌【配图10】稍后处理页

## 五、分组

### 5.1 新建分组

可在分组页或右键菜单中新建分组，为标签归类。

### 5.2 放入分组

- 未分组区提供「新建分组」与「放入已有分组」操作，一气呵成。
- 支持搜索与排序（按时间/ID）。

### 5.3 分组管理

支持分组重命名、删除、折叠/展开。

### 5.4 域名归并

同站点（同一 eTLD+1）的标签可自动归并到一起，便于按网站整理。

## 六、历史

### 6.1 最近关闭

无需任何额外权限，自动记录最近关闭的标签（上限 50 条），可一键恢复。

### 6.2 完整浏览历史

- 完整浏览历史依赖浏览器的「历史记录」权限，首次使用时弹窗引导授权。
- 授权后可在历史页查看完整浏览历史。

## 七、设置

通过侧边栏设置菜单或独立设置页进入。

### 7.1 主题与外观

- **明暗模式**：亮色 / 暗色 / 跟随系统，控制界面底层明暗。
- **卡片密度**：紧凑 / 标准 / 宽松，控制标签卡片间距。
- **字号**：调整界面字体大小。

### 7.2 装扮主题（皮肤背景）

通过装扮商城兑换的主题背景道具，可为侧边栏设置装饰背景：

- **背景图道具**：webp 图片背景。
- **纯色背景道具**：CSS 渐变/纯色背景。
- 已兑换并「使用中」的背景会持续生效，并支持调整背景透明度。
- 支持试穿：选择道具后可临时预览效果（约 30 秒自动到期），满意后再正式兑换使用。

### 7.3 头像框

- 通过装扮商城兑换的头像框道具，应用后显示在侧边栏头像外圈（含动态效果）。
- 同样支持试穿预览。
- 头像框与主题背景可同时使用、互不冲突。

📌【配图13】装扮商城 / 主题背景与头像框效果截图

### 7.4 显示偏好

各区域显隐开关，如搜索栏、标记栏、固定栏等是否显示。

### 7.5 侧边栏位置

侧边栏显示在左侧还是右侧由浏览器控制，插件无法直接切换。可在设置中查看指引，前往浏览器原生右键菜单切换显示位置。

### 7.6 存储管理

查看插件本地存储占用情况，并按数据类型分别清理（如稍后列表、标记、缓存等）。

## 九、常见问题（FAQ）

- **标签数量对不上？** 插件显示的数量与浏览器实际标签保持一致；若出现偏差，刷新侧边栏或重新启用扩展即可恢复。
- **标记丢失？** 自定义标记保存在本地，扩展重装或清理缓存会清除；登录账号后的装扮数据按账号保存。
- **侧边栏不显示？** 在浏览器扩展管理中确认扩展已启用，并检查侧边栏是否被折叠。
- **扩展失效/异常？** 在浏览器扩展页关闭再开启扩展，或重新加载已解压的扩展程序。
